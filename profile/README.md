# Programming Club, DAU

Welcome to the official GitHub organization of **Programming Club, DAU** at **Dhirubhai Ambani University**! 🚀

---

## 🎯 Our Mission

The Programming Club organizes various programming events to strengthen students' coding, problem-solving, and algorithmic thinking skills while fostering a strong competitive programming and coding culture across the university. The club provides a collaborative platform for learning, practice, and preparation for national and international programming competitions.

## 🚀 How to Contribute

We encourage all student members to contribute to our organization repositories:

1. Read our [Contribution Guidelines](https://github.com/ProgrammingClub-DAU/.github/blob/main/CONTRIBUTING.md).
2. Check out open issues labeled `good first issue` or `help wanted`.
3. Fork or branch out, build your feature or fix, and submit a Pull Request!

Please review our [Code of Conduct](https://github.com/ProgrammingClub-DAU/.github/blob/main/CODE_OF_CONDUCT.md) before participating.
