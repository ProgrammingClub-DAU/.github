# Security Policy

At **Programming Club, DAU**, we take the security of our student-built applications, APIs, and community tools seriously. As a university student organization, we appreciate responsible disclosure of any security vulnerabilities found in our repositories.

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential security issue in any repository under the **ProgrammingClub-DAU** organization:

**Please do NOT open a public GitHub issue.**

Instead, report the issue directly to our maintainer team via email:

- **Email**: [programming-club@dau.ac.in](mailto:programming-club@dau.ac.in)
- **Subject Line**: `[SECURITY VULNERABILITY] <Repository Name> - <Brief Description>`

---

## What to Include in Your Report

To help us investigate and address the issue quickly, please include as much of the following information as possible:

1. **Repository Name**: The specific repository affected.
2. **Vulnerability Type**: (e.g., SQL Injection, Cross-Site Scripting, Exposed Credentials, Broken Authentication).
3. **Steps to Reproduce**: Detailed steps, proof-of-concept code, or HTTP requests showing how to reproduce the issue.
4. **Impact**: Potential consequences if exploited.
5. **Suggested Fix**: Any recommended patches or mitigation strategies (if available).

---

## Disclosure Policy

<!-- - We will acknowledge receipt of your vulnerability report within **48 hours**. -->
- We will work with student maintainers to patch the issue promptly.
- We kindly ask that you keep details confidential and refrain from public disclosure until our maintainers have resolved the issue.

Thank you for helping keep the **Dhirubhai Ambani University** Programming community secure!
